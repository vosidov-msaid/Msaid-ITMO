# Документация по архитектуре набора команд (ISA) RISC-IV

RISC-IV — простая регистровая архитектура набора команд, вдохновлённая архитектурой RISC-V. В этой документации описаны инструкции, доступные в ISA RISC-IV, их синтаксис и семантика.

## Обзор архитектуры

RISC-IV — 32-битная RISC-архитектура (Reduced Instruction Set Computer, компьютер с сокращённым набором команд), вдохновлённая спецификацией RISC-V. Её особенности:

- 32 регистра общего назначения (включая один аппаратно обнулённый регистр — запись в `Zero` молча игнорируется)
- Инструкции фиксированной длины 4 байта
- Архитектура load-store (доступ к памяти только через специальные инструкции)
- Простые режимы адресации
- Ввод-вывод, отображённый на память (memory-mapped I/O)
- Поддержка вызова функций и возврата из них через инструкции перехода с сохранением адреса возврата (jump-and-link)
- Арифметические, логические операции и операции управления потоком выполнения

Эта архитектура предлагает чистый ортогональный набор команд, наглядно воплощающий принципы RISC, поэтому она отлично подходит для обучения и при этом достаточно мощна для практического применения.

Комментарии в ассемблере RISC-IV обозначаются символом `;`.

Вдохновлено [RISC-V](https://riscv.org/wp-content/uploads/2017/05/riscv-spec-v2.2.pdf)

### Соглашения об использовании регистров

Хотя технически большинство регистров можно использовать для любых целей, рекомендуется придерживаться следующих соглашений

| Регистр(ы) | Назначение                                                                              | Соглашение                    |
| ---------- | --------------------------------------------------------------------------------------- | ----------------------------- |
| `Zero`     | Константа ноль. Запись игнорируется                                                     | Неизменяемый                  |
| `Ra`       | Адрес возврата при вызове функций                                                       | Сохраняет вызывающий          |
| `Sp`       | Указатель стека                                                                         | Сохраняет вызываемый          |
| `Gp`       | Глобальный указатель. Указывает на область с часто используемыми глобальными данными    | Сохраняет вызываемый          |
| `Tp`       | Указатель потока. Зарезервирован для локальных данных потока                            | Сохраняет вызываемый          |
| `A0-A7`    | Аргументы функций и возвращаемые значения                                               | Сохраняет вызывающий          |
| `T0-T6`    | Временные регистры для промежуточных вычислений                                         | Сохраняет вызывающий          |
| `S0Fp`     | Указатель кадра или сохраняемый регистр                                                 | Сохраняет вызываемый          |
| `S1-S11`   | Сохраняемые регистры для долгоживущих значений                                          | Сохраняет вызываемый          |

Регистры, которые **сохраняет вызывающий** (caller-saved), вызываемая функция может свободно изменять. Если значения этих регистров нужны вызывающему после вызова функции, он должен сам их сохранить и восстановить

Регистры, которые **сохраняет вызываемый** (callee-saved), должны сохранять свои значения между вызовами функций. Функция, изменяющая такой регистр, обязана восстановить его исходное значение перед возвратом

## Директивы перемещения непосредственных значений (relocation)

Ассемблер RISC-IV предоставляет специальные директивы для работы с большими непосредственными значениями, которые не помещаются в стандартные форматы инструкций:

- **%hi(symbol)**
    - **Описание:** Извлечь старшие 20 бит 32-битного адреса или непосредственного значения. Значение сначала округляется вверх на половину поля `%lo` (`+0x800`), чтобы компенсировать знаковое расширение, которому подвергается `%lo`.
    - **Использование:** `lui rd, %hi(symbol)`
    - **Операция:** `%hi(symbol) = ((symbol + 0x800) >> 12) & 0xFFFFF`

- **%lo(symbol)**
    - **Описание:** Извлечь младшие 12 бит 32-битного адреса или непосредственного значения **со знаковым расширением от бита 11**, поскольку каждая инструкция, принимающая 12-битное непосредственное значение, расширяет его знаком. Поэтому `%lo(0xFFFFFFFF)` равно `-1`, а не `0xFFF`, и `addi rd, zero, -1` и `addi rd, zero, %lo(-1)` дают одинаковый результат.
    - **Использование:** `addi rd, rs, %lo(symbol)`
    - **Операция:** `%lo(symbol) = signext(symbol[11:0])`

Обычно эти директивы используются вместе, чтобы загрузить в регистр полный 32-битный адрес. Слагаемое `+0x800` в `%hi` компенсирует заём, возникающий при отрицательном `%lo`, поэтому пара директив точно восстанавливает любое 32-битное значение:

```assembly
lui  a0, %hi(address)    ; Загрузить старшие 20 бит в a0
addi a0, a0, %lo(address) ; Прибавить младшие 12 бит к a0
```

## Инструкции

Размер инструкции: 4 байта.

### Поля непосредственных значений и смещений

Каждое непосредственное значение, смещение и сдвиг адреса должны поместиться в 4-байтовую инструкцию,
которая их содержит, поэтому ни одно из этих полей не может вместить полное 32-битное значение:

| Поле                                                                    | Ширина               | Допустимые значения     |
| ----------------------------------------------------------------------- | -------------------- | ----------------------- |
| смещение `lw`, `lb`, `sw`, `sb`                                         | 12 бит со знаком     | `-2048..2047`           |
| непосредственное значение `addi`, `slti`, `andi`, `ori`, `xori`         | 12 бит со знаком     | `-2048..2047`           |
| величина сдвига `slli`, `srli`, `srai`                                  | 5 бит без знака      | `0..31`, константа      |
| смещение перехода `beqz`, `bnez`, `beq`, `bne`, `blt`, `bge`, `bltu`, `bgeu` | 13 бит со знаком | `-4096..4095`           |
| смещение перехода `j`, `jal`                                            | 21 бит со знаком     | `-1048576..1048575`     |
| непосредственное значение `lui`                                         | 20 бит без знака     | `0..1048575`            |

Значение, выходящее за пределы своего поля, вообще не имеет кодировки, поэтому это ошибка трансляции,
а не программа, которая молча делает что-то другое. Смещение в памяти проверяется во время разбора,
поэтому ошибка сообщается с указанием позиции операнда:

```text
error (risc-iv-32): program.s:3:12:
  |
3 |     lw a0, 0x1FFF00(zero)
  |            ^
offset 2096896 doesn't fit the 12-bit signed field of a 4 byte instruction, expected -2048..2047
```

Литерал, не помещающийся в 32-битное машинное слово, отклоняется ещё раньше, до проверки какого-либо
поля, поскольку он в принципе не может попасть в регистр:

```text
error (risc-iv-32): program.s:3:20:
  |
3 |     addi t0, zero, 4294967296
  |                    ^
literal 4294967296 doesn't fit a 32-bit machine word, expected -2147483648..4294967295
```

Там допускается всё, что можно записать битами слова, со знаком или без, поэтому `0xFFFFFFFF` и `-1`
обозначают одно и то же слово, и оба затем проверяются на соответствие 12-битному полю как `-1`.

Непосредственные значения и смещения переходов можно записывать метками, поэтому они проверяются
после разрешения меток. Сообщение указывает на операнд и называет мнемонику и поле:

```text
error (risc-iv-32): program.s:3:17: beq: B-type disp 8192 is not in -4096..4095
```

Смещение перехода — это расстояние до цели, а не сама цель, записанная в исходном коде (см.
[Адреса переходов и ветвлений](#адреса-переходов-и-ветвлений)), поэтому ветвление по адресу `0x100`
на `0x2100` сообщается как `disp 8192`.

Чтобы получить в регистре широкую константу или адрес, используйте `lui`/`addi` с описанными выше
директивами `%hi`/`%lo`, а затем работайте через этот регистр. `%lo` также позволяет уложить битовый
шаблон в поле: `addi rd, rs, %lo(0x800)` — это способ записать непосредственное значение `-2048` как
биты `0x800`, поскольку просто `0x800` выходит за пределы диапазона.

#### Адреса переходов и ветвлений

Ветвления (`beqz`, `bnez`, `beq`, `bne`, `blt`, `bge`, `bltu`, `bgeu`) и переходы (`j`, `jal`)
записываются с абсолютным целевым адресом. Метка и числовой литерал означают одно и то же:
`j loop` и `j 0x40` оба ведут на `0x40`, если там находится `loop`.

Относителен только машинный код. Транслятор кодирует смещение `k = <address> - pc`, где `pc` — адрес
самой инструкции ветвления, а процессор прибавляет его обратно: `pc <- pc + k`.

```asm
    .text
    .org 0x40
loop:
    addi    t0, t0, -1      ; 0x40
    bnez    t0, loop        ; 0x44: = bnez t0, 0x40, кодируется как k = 0x40 - 0x44 = -4
    j       0x50            ; 0x48: кодируется как k = 0x50 - 0x48 = 8
```

Пошаговый отчёт показывает инструкцию так, как её видит машина, поэтому `bnez t0, loop` из примера
выше отображается как `Bnez {rs1 = T0, k = -4}`.

`jalr` не относительна: её непосредственное значение прибавляется к регистру, поэтому оно остаётся
обычным числом.

#### Смещения переходов и ветвлений не масштабируются (особенность RISC-IV)

RISC-V кодирует смещение ветвления или перехода в единицах по два байта: бит 0 не хранится и считается
равным нулю, что там ничего не стоит, поскольку ни одна инструкция не может начинаться с нечётного
адреса. В этом RISC-IV отличается от RISC-V: смещение хранится как обычное знаковое число, включая
бит 0. Поэтому приведённые выше интервалы — это полный знаковый диапазон каждого поля, включая
нечётные смещения, тогда как RISC-V допускал бы только чётные значения вдвое более широкого диапазона.

Также ничто не требует, чтобы цель попадала на границу инструкции. Каждая инструкция RISC-IV занимает
4 байта, поэтому цель, не кратная 4, указывает в середину инструкции, и переход завершается ошибкой
при выборке по этому адресу (`j 6` по адресу `0`):

```text
0: J {k = 6}
ERROR: memory[0x06]: instruction in memory corrupted
```

### Инструкции перемещения данных

- **Загрузка старшей части непосредственного значения (Load Upper Immediate)**
    - **Синтаксис:** `lui <rd>, <k>`
    - **Описание:** Загрузить в регистр-приёмник непосредственное значение, сдвинутое влево на 12 бит.
    - **Операция:** `rd <- (k & 0x000FFFFF) << 12`

- **Пересылка (Move)**
    - **Синтаксис:** `mv <rd>, <rs>`
    - **Описание:** Переслать значение из регистра-источника в регистр-приёмник.
    - **Операция:** `rd <- rs`

- **Сохранение слова (Store Word)**
    - **Синтаксис:** `sw <rs2>, <offset>(<rs1>)`
    - **Описание:** Сохранить значение регистра-источника в память по адресу, вычисленному как сумма смещения и базового регистра.
    - **Операция:** `M[offset + rs1] <- rs2`

- **Сохранение байта (Store Byte)**
    - **Синтаксис:** `sb <rs2>, <offset>(<rs1>)`
    - **Описание:** Сохранить младшие 8 бит значения регистра-источника в память по адресу, вычисленному как сумма смещения и базового регистра.
    - **Операция:** `M[offset + rs1] <- rs2 & 0xFF`

- **Загрузка слова (Load Word)**
    - **Синтаксис:** `lw <rd>, <offset>(<rs1>)`
    - **Описание:** Загрузить в регистр-приёмник слово из памяти по адресу, вычисленному как сумма смещения и базового регистра.
    - **Операция:** `rd <- M[offset + rs1]`

- **Загрузка байта (Load Byte)**
    - **Синтаксис:** `lb <rd>, <offset>(<rs1>)`
    - **Описание:** Загрузить байт из памяти по адресу, вычисленному как сумма смещения и базового регистра, расширить его знаком до 32 бит и записать в регистр-приёмник.
    - **Операция:** `rd <- signext(M[offset + rs1][7:0])`

### Арифметические инструкции

- **Сложение с непосредственным значением (Add Immediate)**
    - **Синтаксис:** `addi <rd>, <rs1>, <k>`
    - **Описание:** Прибавить к регистру-источнику 12-битное непосредственное значение со знаковым расширением и записать результат в регистр-приёмник. Знак берётся из бита 11 поля, поэтому `%lo(0x800)` равно `-2048`.
    - **Операция:** `rd <- rs1 + signext(k[11:0])`

- **Установка, если меньше непосредственного значения (Set Less Than Immediate)**
    - **Синтаксис:** `slti <rd>, <rs1>, <k>`
    - **Описание:** Записать в регистр-приёмник 1, если регистр-источник меньше непосредственного значения (сравнение со знаком), иначе записать 0. Как и в `addi`, непосредственное значение расширяется знаком от бита 11.
    - **Операция:** `rd <- (rs1 < signext(k[11:0])) ? 1 : 0`

- **Сложение (Add)**
    - **Синтаксис:** `add <rd>, <rs1>, <rs2>`
    - **Описание:** Сложить значения двух регистров-источников и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 + rs2`

- **Вычитание (Subtract)**
    - **Синтаксис:** `sub <rd>, <rs1>, <rs2>`
    - **Описание:** Вычесть значение второго регистра-источника из первого и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 - rs2`

- **Умножение (Multiply)**
    - **Синтаксис:** `mul <rd>, <rs1>, <rs2>`
    - **Описание:** Перемножить значения двух регистров-источников и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 * rs2`

- **Умножение, старшая часть (Multiply High)**
    - **Синтаксис:** `mulh <rd>, <rs1>, <rs2>`
    - **Описание:** Перемножить значения двух регистров-источников и записать старшую часть результата в регистр-приёмник.
    - **Операция:** `rd <- (rs1 * rs2) >> (word size)`

- **Деление (Divide)**
    - **Синтаксис:** `div <rd>, <rs1>, <rs2>`
    - **Описание:** Разделить значение первого регистра-источника на значение второго и записать результат в регистр-приёмник. Частное округляется к нулю, как в RISC-V: `-7 / 2 = -3`. Деление на ноль даёт `-1`, `-2^31 / -1` даёт `-2^31`.
    - **Операция:** `rd <- rs1 / rs2`

- **Остаток (Remainder)**
    - **Синтаксис:** `rem <rd>, <rs1>, <rs2>`
    - **Описание:** Вычислить остаток от деления первого регистра-источника на второй и записать результат в регистр-приёмник. Остаток имеет знак делимого: `-7 % 2 = -1`. Остаток от деления на ноль равен `rs1`, `-2^31 % -1` даёт `0`.
    - **Операция:** `rd <- rs1 % rs2`

### Побитовые инструкции

- **Логический сдвиг влево на непосредственное значение (Logical Shift Left Immediate)**
    - **Синтаксис:** `slli <rd>, <rs1>, <k>`
    - **Описание:** Сдвинуть значение регистра-источника влево на непосредственно заданную величину — константу в диапазоне `0..31`, но не метку — и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 << k`

- **Логический сдвиг вправо на непосредственное значение (Logical Shift Right Immediate)**
    - **Синтаксис:** `srli <rd>, <rs1>, <k>`
    - **Описание:** Сдвинуть значение регистра-источника вправо (с заполнением нулями) на непосредственно заданную величину — константу в диапазоне `0..31`, но не метку — и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 >>> k`

- **Арифметический сдвиг вправо на непосредственное значение (Arithmetic Shift Right Immediate)**
    - **Синтаксис:** `srai <rd>, <rs1>, <k>`
    - **Описание:** Сдвинуть значение регистра-источника вправо на непосредственно заданную величину — константу в диапазоне `0..31`, но не метку — с сохранением знака и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 >> k`

- **Логический сдвиг влево (Logical Shift Left)**
    - **Синтаксис:** `sll <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвинуть значение первого регистра-источника влево на количество бит, заданное младшими 5 битами второго регистра-источника, и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 << (rs2 & 0x1F)`

- **Логический сдвиг вправо (Logical Shift Right)**
    - **Синтаксис:** `srl <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвинуть значение первого регистра-источника вправо на количество бит, заданное младшими 5 битами второго регистра-источника, и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 >> (rs2 & 0x1F)`

- **Арифметический сдвиг вправо (Arithmetic Shift Right)**
    - **Синтаксис:** `sra <rd>, <rs1>, <rs2>`
    - **Описание:** Сдвинуть значение первого регистра-источника вправо на количество бит, заданное младшими 5 битами второго регистра-источника, с сохранением знака и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 >> (rs2 & 0x1F)`

- **Побитовое И (Bitwise AND)**
    - **Синтаксис:** `and <rd>, <rs1>, <rs2>`
    - **Описание:** Выполнить побитовое И над значениями двух регистров-источников и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 & rs2`

- **Побитовое И с непосредственным значением (Bitwise AND Immediate)**
    - **Синтаксис:** `andi <rd>, <rs1>, <k>`
    - **Описание:** Выполнить побитовое И регистра-источника с 12-битным непосредственным значением со знаковым расширением. Поскольку поле расширяется знаком, самая широкая маска младших бит, которую может выразить `andi`, — это 11 бит `0x7FF`. Отрицательное непосредственное значение, наоборот, обнуляет младшие биты: `-16` — это `0xFFFFFFF0`. `%lo(0xFFF)` равно `-1`, поэтому оставляет регистр без изменений.
    - **Операция:** `rd <- rs1 & signext(k[11:0])`

- **Побитовое ИЛИ (Bitwise OR)**
    - **Синтаксис:** `or <rd>, <rs1>, <rs2>`
    - **Описание:** Выполнить побитовое ИЛИ над значениями двух регистров-источников и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 | rs2`

- **Побитовое ИЛИ с непосредственным значением (Bitwise OR Immediate)**
    - **Синтаксис:** `ori <rd>, <rs1>, <k>`
    - **Описание:** Выполнить побитовое ИЛИ регистра-источника с 12-битным непосредственным значением со знаковым расширением.
    - **Операция:** `rd <- rs1 | signext(k[11:0])`

- **Побитовое исключающее ИЛИ (Bitwise XOR)**
    - **Синтаксис:** `xor <rd>, <rs1>, <rs2>`
    - **Описание:** Выполнить побитовое исключающее ИЛИ над значениями двух регистров-источников и записать результат в регистр-приёмник.
    - **Операция:** `rd <- rs1 ^ rs2`

- **Побитовое исключающее ИЛИ с непосредственным значением (Bitwise XOR Immediate)**
    - **Синтаксис:** `xori <rd>, <rs1>, <k>`
    - **Описание:** Выполнить побитовое исключающее ИЛИ регистра-источника с 12-битным непосредственным значением со знаковым расширением.
    - **Операция:** `rd <- rs1 ^ signext(k[11:0])`

### Инструкции управления потоком выполнения

- **Безусловный переход (Jump)**
    - **Синтаксис:** `j <address>`
    - **Описание:** Перейти по адресу. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `pc <- pc + k`

- **Переход с сохранением адреса возврата (Jump and Link)**
    - **Синтаксис:** `jal <rd>, <address>`
    - **Описание:** Записать адрес следующей инструкции в регистр-приёмник и перейти по адресу. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `rd <- pc + 4, pc <- pc + k`

- **Переход по регистру с сохранением адреса возврата (Jump and Link Register)**
    - **Синтаксис:** `jalr <rd>, <rs1>, <k>`
    - **Описание:** Записать адрес следующей инструкции в регистр-приёмник и перейти по адресу, вычисленному как сумма непосредственного значения и регистра-источника. Для возврата из вызова используйте `jalr zero, ra, 0`.
    - **Операция:** `rd <- pc + 4, pc <- rs1 + k`

- **Переход, если равно нулю (Branch if Equal to Zero)**
    - **Синтаксис:** `beqz <rs1>, <address>`
    - **Описание:** Перейти по адресу, если значение регистра-источника равно нулю. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 == 0 then pc <- pc + k`

- **Переход, если не равно нулю (Branch if Not Equal to Zero)**
    - **Синтаксис:** `bnez <rs1>, <address>`
    - **Описание:** Перейти по адресу, если значение регистра-источника не равно нулю. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 != 0 then pc <- pc + k`

- **Переход, если меньше (Branch if Less Than)**
    - **Синтаксис:** `blt <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника меньше значения второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 < rs2 then pc <- pc + k`

- **Переход, если больше или равно (Branch if Greater Than or Equal)**
    - **Синтаксис:** `bge <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника больше или равно значению второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 >= rs2 then pc <- pc + k`

- **Переход, если меньше (без знака) (Branch if Less Than (Unsigned))**
    - **Синтаксис:** `bltu <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника, интерпретируемое как беззнаковое, меньше беззнакового значения второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if unsigned(rs1) < unsigned(rs2) then pc <- pc + k`

- **Переход, если больше или равно (без знака) (Branch if Greater Than or Equal (Unsigned))**
    - **Синтаксис:** `bgeu <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника, интерпретируемое как беззнаковое, больше или равно беззнаковому значению второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if unsigned(rs1) >= unsigned(rs2) then pc <- pc + k`

- **Переход, если равно (Branch if Equal)**
    - **Синтаксис:** `beq <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника равно значению второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 == rs2 then pc <- pc + k`

- **Переход, если не равно (Branch if Not Equal)**
    - **Синтаксис:** `bne <rs1>, <rs2>, <address>`
    - **Описание:** Перейти по адресу, если значение первого регистра-источника не равно значению второго. Кодируется как смещение `k = <address> - pc`.
    - **Операция:** `if rs1 != rs2 then pc <- pc + k`

- **Останов (Halt)**
    - **Синтаксис:** `halt`
    - **Описание:** Остановить машину.

## Специфичные для ISA представления состояния

- `<reg>:dec`, `<reg>:hex` — значение указанного регистра в десятичном или шестнадцатеричном формате.

Доступные регистры: `Zero`, `Ra`, `Sp`, `Gp`, `Tp`, `T0`, `T1`, `T2`, `S0Fp`, `S1`, `A0`, `A1`, `A2`, `A3`, `A4`, `A5`, `A6`, `A7`, `S2`, `S3`, `S4`, `S5`, `S6`, `S7`, `S8`, `S9`, `S10`, `S11`, `T3`, `T4`, `T5`, `T6`.
