# Документация по архитектуре набора команд (ISA) M68k

M68k — простая CISC-подобная архитектура набора команд, вдохновлённая архитектурой Motorola 68000. В этой документации описаны инструкции, доступные в ISA M68k, их синтаксис и семантика.

## Обзор архитектуры

M68k — 32-битная CISC-архитектура (Complex Instruction Set Computer, компьютер со сложным набором команд), вдохновлённая семейством Motorola 68000. Её особенности:

- 8 регистров данных общего назначения (D0–D7)
- 8 адресных регистров (A0–A7, A7 служит указателем стека)
- Разнообразные режимы адресации для гибкого доступа к памяти
- Богатый набор инструкций с операндами разного размера
- Регистр состояния с флагами условий
- Ввод-вывод, отображённый на память (memory-mapped I/O)

Эта архитектура сочетает простоту RISC-подхода с функциональным богатством CISC-процессоров, поэтому она отлично подходит для знакомства с более сложными процессорами.

Комментарии в ассемблере M68k обозначаются символом `;`.

- [Wiki: Motorola 68000](https://en.wikipedia.org/wiki/Motorola_68000)

## Специфичные для ISA представления состояния

- `D<n>:dec`, `D<n>:hex` — регистры данных (D0–D7).
- `A<n>:dec`, `A<n>:hex` — адресные регистры (A0–A7).
- `PC:dec`, `PC:hex` — счётчик команд (Program Counter).
- `SR:bin` — регистр состояния (флаги: N, Z, V, C).

### Использование памяти и регистров

- **Регистры данных (D0–D7):** регистры общего назначения для арифметических, логических операций и обработки данных.
- **Адресные регистры (A0–A7):** используются для адресации памяти. A7 также является указателем стека (SP).
- **Регистр состояния (SR):** содержит коды условий (флаги):
    - **N (Negative, отрицательный):** устанавливается, если результат операции отрицателен.
    - **Z (Zero, ноль):** устанавливается, если результат операции равен нулю.
    - **V (Overflow, переполнение):** устанавливается при арифметическом переполнении.
    - **C (Carry, перенос):** устанавливается при переносе или заёме в арифметических операциях.

## Инструкции

Размер инструкций зависит от режима операции и используемых режимов адресации. Расчёт ByteSize теперь учитывает разницу между байтовыми и длинными операциями: байтовые операции, как правило, занимают меньше памяти, чем длинные.

### Поля операндов

Большинство операндов здесь занимают полное машинное слово, но четыре из них уже, и значение, не
помещающееся в своё поле, — это ошибка трансляции, а не программа, которая молча делает что-то другое:

| Операнд                                                    | Ширина            | Допустимые значения    |
| ---------------------------------------------------------- | ----------------- | ---------------------- |
| смещение в `d(An)` и `link An, d`                          | 16 бит со знаком  | `-32768..32767`        |
| смещение в `d(An, Xn)`                                     | 8 бит со знаком   | `-128..127`            |
| непосредственный счётчик сдвига в `asl`, `asr`, `lsl`, `lsr` | величина сдвига | `0..31`                |
| непосредственный источник операции `.b`                    | байт              | `-128..255`            |
| непосредственный источник операции `.l`, цель перехода     | полное слово      | любое машинное слово   |

```text
error (m68k): program.s:4:13: asl.l: shift count 100 is not in 0..31
error (m68k): program.s:3:13: move.b: immediate 300 is not in -128..255
```

Смещение проверяется во время разбора, поэтому ошибка сообщается с «кареткой» (`^`) под операндом.
Индексной форме достаётся только байт, потому что она делит краткое слово расширения со своим
индексным регистром, тогда как у `d(An)` и `link` слово расширения целиком в их распоряжении.

Счётчик сдвига — это количество бит, а не адрес, поэтому там допускается только константа, а метка
отклоняется. Все остальные непосредственные операнды принимают метку, но операция `.b` всё равно
читает из неё лишь один байт, так что метка с адресом дальше `255` в такой операнд тоже не помещается.

### Режимы операций

Инструкции M68k могут работать с данными разного размера:

- **Байт (`.b`):** 8-битные операции
- **Длинное слово (`.l`):** 32-битные операции

Суффикс размера обязателен и должен явно указываться для всех инструкций, которые его поддерживают.

Пример: `add.b D0, D1` работает с младшими байтами D0 и D1.

> **Примечание о реализации ByteSize:** реализация ByteSize для инструкций теперь различает байтовые и длинные операции. Байтовые операции (`.b`) используют 1 байт для данных, а длинные (`.l`) — 4 байта. Все инструкции перехода и ветвления всегда используют длинную (6-байтовую) кодировку независимо от смещения.

### Режимы адресации

ISA M68k поддерживает следующие режимы адресации:

1. **Прямая регистровая адресация**
   - **Прямая адресация регистра данных**: от `D0` до `D7` — может быть источником или приёмником в любой инструкции, принимающей операнд.
   - **Прямая адресация адресного регистра**: от `A0` до `A7` — допускается только как источник/приёмник `movea` и как операнд-адресный регистр в `link`/`unlk`. Остальные инструкции отклоняют `An` в позиции операнда с ошибкой разбора; чтобы получить значение адресного регистра, сначала используйте `movea` или один из косвенных режимов ниже.

2. **Непосредственная адресация**: `value`
   - Пример: `move.l 42, D0`

3. **Адресация памяти**
   - **Косвенная через адресный регистр**: `(An)`
     - Обращается к памяти по адресу, содержащемуся в An
     - Пример: `move.l (A0), D0`

   - **Косвенная через адресный регистр с постинкрементом**: `(An)+`
     - Использует адрес из An, затем увеличивает An на размер операции (1 для байта, 4 для длинного слова)
     - Пример: `move.l (A0)+, D0`

   - **Косвенная через адресный регистр с предекрементом**: `-(An)`
     - Уменьшает An на размер операции, затем использует полученный адрес
     - Пример: `move.l -(A0), D0`

   - **Косвенная через адресный регистр со смещением**: `d(An)`
     - Использует адрес из An плюс 16-битное смещение со знаком d
     - Пример: `move.l 8(A0), D0` или `move.l -4(A0), D0`

   - **Косвенная через адресный регистр с индексом**: `d(An,Xn)`
     - Использует адрес из An плюс значение Xn (это может быть регистр данных или адресный регистр) плюс смещение со знаком d
     - Пример: `move.l 4(A0,D1), D0` или `move.l 8(A0,A1), D0`

### Инструкции перемещения данных

- **Пересылка (Move)**
    - **Синтаксис:** `move.<size> <source>, <destination>`
    - **Описание:** Переслать данные из источника в приёмник. Устанавливает флаги N и Z по результату, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- <source>`
    - **Примеры:**

      ```assembly
      move.l D0, D1       ; Скопировать D0 в D1 (32 бита)
      move.b D0, D1       ; Скопировать младший байт D0 в младший байт D1
      move.l 42, D0       ; Загрузить непосредственное значение 42 в D0
      move.l (A0), D0     ; Загрузить в D0 значение из памяти по адресу из A0
      move.l D0, (A1)     ; Сохранить значение D0 в память по адресу из A1
      move.l (A0)+, D0    ; Загрузить значение по адресу A0, затем увеличить A0 на 4
      move.l -(A0), D0    ; Уменьшить A0 на 4, затем загрузить значение по адресу A0
      move.l 8(A0), D0    ; Загрузить значение по адресу A0+8
      move.l -4(A0), D0   ; Загрузить значение по адресу A0-4
      move.l 8(A0,D1), D0 ; Загрузить значение по адресу A0+D1+8
      move.l 4(A0,A1), D0 ; Загрузить значение по адресу A0+A1+4
      ```

- **Пересылка в адресный регистр (Move to Address Register)**
    - **Синтаксис:** `movea.l <source>, <destination>`
    - **Описание:** Переслать данные из источника в адресный регистр-приёмник. `movea` — единственная инструкция, принимающая `An` в качестве прямого операнда-источника; остальные инструкции отклоняют `An` на этапе разбора. `movea` существует только в длинной форме (формы `.b` нет). Не влияет на флаги.
    - **Операция:** `<destination> <- <source>`
    - **Примеры:**

      ```assembly
      movea.l 1000, A0    ; Загрузить непосредственное значение 1000 в A0
      movea.l D0, A1      ; Скопировать D0 в A1
      movea.l A2, A0      ; Скопировать A2 в A0 (единственное место, где An допустим как источник)
      ```

### Логические инструкции

- **Очистка (Clear)**
    - **Синтаксис:** `clr.<size> <destination>`
    - **Описание:** Обнулить приёмник. Устанавливает флаг Z, сбрасывает флаги N, V и C.
    - **Операция:** `<destination> <- 0`
    - **Примеры:**

      ```assembly
      clr.l D0            ; D0 <- 0 (32 бита)
      clr.b D0            ; Обнулить младший байт D0
      ```

- **Смена знака (Negate)**
    - **Синтаксис:** `neg.<size> <destination>`
    - **Описание:** Сменить знак приёмника (вычислить 0 − приёмник). Устанавливает флаги N, Z, V и C по результату.
    - **Операция:** `<destination> <- 0 - <destination>`
    - **Примеры:**

      ```assembly
      neg.l D0            ; D0 <- -D0 (32 бита)
      neg.b D0            ; Сменить знак младшего байта D0
      ```

- **НЕ (Not)**
    - **Синтаксис:** `not.<size> <destination>`
    - **Описание:** Побитовое НЕ приёмника. Устанавливает флаги N и Z по результату, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- ~<destination>`
    - **Примеры:**

      ```assembly
      not.l D0            ; D0 <- ~D0 (32 бита)
      not.b D0            ; Применить НЕ к младшему байту D0
      ```

- **И (And)**
    - **Синтаксис:** `and.<size> <source>, <destination>`
    - **Описание:** Побитовое И источника с приёмником. Устанавливает флаги N и Z по результату, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- <destination> & <source>`
    - **Примеры:**

      ```assembly
      and.l D0, D1        ; D1 <- D1 & D0 (32 бита)
      and.b D0, D1        ; И младших байтов D0 и D1
      ```

- **ИЛИ (Or)**
    - **Синтаксис:** `or.<size> <source>, <destination>`
    - **Описание:** Побитовое ИЛИ источника с приёмником. Устанавливает флаги N и Z по результату, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- <destination> | <source>`
    - **Примеры:**

      ```assembly
      or.l D0, D1         ; D1 <- D1 | D0 (32 бита)
      or.b D0, D1         ; ИЛИ младших байтов D0 и D1
      ```

- **Исключающее ИЛИ (Exclusive Or)**
    - **Синтаксис:** `xor.<size> <source>, <destination>`
    - **Описание:** Побитовое исключающее ИЛИ источника с приёмником. Устанавливает флаги N и Z по результату, сбрасывает флаги V и C.
    - **Операция:** `<destination> <- <destination> ^ <source>`
    - **Примеры:**

      ```assembly
      xor.l D0, D1        ; D1 <- D1 ^ D0 (32 бита)
      xor.b D0, D1        ; Исключающее ИЛИ младших байтов D0 и D1
      ```

### Арифметические инструкции

- **Сложение (Add)**
    - **Синтаксис:** `add.<size> <source>, <destination>`
    - **Описание:** Прибавить источник к приёмнику.
    - **Операция:** `<destination> <- <destination> + <source>`
    - **Примеры:**

      ```assembly
      add.l D0, D1        ; D1 <- D1 + D0 (32 бита)
      add.b D0, D1        ; Сложить младшие байты D0 и D1
      add.l 10, D0        ; D0 <- D0 + 10
      add.b 5, D0         ; Прибавить 5 к младшему байту D0
      ```

- **Вычитание (Subtract)**
    - **Синтаксис:** `sub.<size> <source>, <destination>`
    - **Описание:** Вычесть источник из приёмника.
    - **Операция:** `<destination> <- <destination> - <source>`
    - **Примеры:**

      ```assembly
      sub.l D0, D1        ; D1 <- D1 - D0 (32 бита)
      sub.b D0, D1        ; Вычесть младший байт D0 из младшего байта D1
      sub.l 1, D0         ; D0 <- D0 - 1
      sub.b 1, D0         ; Вычесть 1 из младшего байта D0
      ```

- **Сравнение (Compare)**
    - **Синтаксис:** `cmp.<size> <source>, <destination>`
    - **Описание:** Сравнить приёмник с источником: вычесть источник из приёмника и установить коды условий соответствующим образом, не сохраняя результат.
    - **Операция:** `temp <- <destination> - <source>` (устанавливаются только флаги)
    - **Примеры:**

      ```assembly
      cmp.l D0, D1        ; Сравнить D1 с D0 (32 бита)
      cmp.b D0, D1        ; Сравнить младшие байты D1 и D0
      cmp.l 10, D0        ; Сравнить D0 с непосредственным значением 10
      cmp.b 5, D0         ; Сравнить младший байт D0 с 5
      cmp.l (A0), D0      ; Сравнить D0 со значением в памяти по адресу из A0
      ```

- **Умножение (Multiply)**
    - **Синтаксис:** `mul.<size> <source>, <destination>`
    - **Описание:** Умножить приёмник на источник.
    - **Операция:** `<destination> <- <destination> * <source>`
    - **Примеры:**

      ```assembly
      mul.l D0, D1        ; D1 <- D1 * D0 (32 бита)
      mul.b D0, D1        ; Перемножить младшие байты D0 и D1
      ```

- **Деление (Divide)**
    - **Синтаксис:** `div.<size> <source>, <destination>`
    - **Описание:** Разделить приёмник на источник.
    - **Операция:** `<destination> <- <destination> / <source>`
    - **Примеры:**

      ```assembly
      div.l D0, D1        ; D1 <- D1 / D0 (32 бита)
      div.b D0, D1        ; Деление по младшим байтам регистров
      ```

### Инструкции сдвига и вращения

- **Арифметический сдвиг влево (Arithmetic Shift Left)**
    - **Синтаксис:** `asl.<size> <source>, <destination>`
    - **Описание:** Арифметически сдвинуть приёмник влево на количество бит, заданное источником. Счётчик в регистре берётся по модулю 64, как это делает 68000, а счётчик, достигающий разрядности данных, полностью «выдвигает» значение; непосредственный счётчик должен быть в диапазоне `0..31`. Устанавливает флаги N и Z по результату, флаг C — равным последнему выдвинутому биту (0, если счётчик сдвига равен 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> << <source>`
    - **Примеры:**

      ```assembly
      asl.l 2, D0         ; D0 <- D0 << 2 (32 бита)
      asl.b 2, D0         ; Сдвинуть младший байт D0 влево на 2 бита
      asl.l D1, D0        ; D0 <- D0 << D1
      ```

- **Арифметический сдвиг вправо (Arithmetic Shift Right)**
    - **Синтаксис:** `asr.<size> <source>, <destination>`
    - **Описание:** Арифметически сдвинуть приёмник вправо на количество бит, заданное источником. Счётчик в регистре берётся по модулю 64, как это делает 68000, непосредственный счётчик должен быть в диапазоне `0..31`. Устанавливает флаги N и Z по результату, флаг C — равным последнему выдвинутому биту (0, если счётчик сдвига равен 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> >> <source>` (с сохранением знака)
    - **Примеры:**

      ```assembly
      asr.l 2, D0         ; D0 <- D0 >> 2 (32 бита)
      asr.b 2, D0         ; Сдвинуть младший байт D0 вправо на 2 бита
      asr.l D1, D0        ; D0 <- D0 >> D1
      ```

- **Логический сдвиг влево (Logical Shift Left)**
    - **Синтаксис:** `lsl.<size> <source>, <destination>`
    - **Описание:** Логически сдвинуть приёмник влево на количество бит, заданное источником. Счётчик в регистре берётся по модулю 64, как это делает 68000, непосредственный счётчик должен быть в диапазоне `0..31`. Устанавливает флаги N и Z по результату, флаг C — равным последнему выдвинутому биту (0, если счётчик сдвига равен 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> << <source>`
    - **Примеры:**

      ```assembly
      lsl.l 2, D0         ; D0 <- D0 << 2 (32 бита)
      lsl.b 2, D0         ; Сдвинуть младший байт D0 влево на 2 бита
      lsl.l D1, D0        ; D0 <- D0 << D1
      ```

- **Логический сдвиг вправо (Logical Shift Right)**
    - **Синтаксис:** `lsr.<size> <source>, <destination>`
    - **Описание:** Логически сдвинуть приёмник вправо на количество бит, заданное источником. Счётчик в регистре берётся по модулю 64, как это делает 68000, непосредственный счётчик должен быть в диапазоне `0..31`. Устанавливает флаги N и Z по результату, флаг C — равным последнему выдвинутому биту (0, если счётчик сдвига равен 0), сбрасывает флаг V.
    - **Операция:** `<destination> <- <destination> >> <source>` (с заполнением нулями)
    - **Примеры:**

      ```assembly
      lsr.l 2, D0         ; D0 <- D0 >> 2 (32 бита)
      lsr.b 2, D0         ; Сдвинуть младший байт D0 вправо на 2 бита
      lsr.l D1, D0        ; D0 <- D0 >> D1
      ```

### Инструкции управления потоком выполнения

- **Безусловный переход (Jump)**
    - **Синтаксис:** `jmp <label>`
    - **Описание:** Перейти на указанную метку.
    - **Операция:** `PC <- <label>`
    - **Примеры:**

      ```assembly
      jmp loop            ; Перейти на метку "loop"
      ```

- **Переход, если перенос сброшен (Branch if Carry Clear)**
    - **Синтаксис:** `bcc <label>`
    - **Описание:** Перейти на указанную метку, если флаг переноса сброшен.
    - **Операция:** `if C == 0 then PC <- <label>`
    - **Примеры:**


- **Создание кадра (Link)**
    - **Синтаксис:** `link <address_register>, <offset>`
    - **Описание:** Создаёт кадр стека для подпрограммы: устанавливает новый указатель кадра и выделяет в стеке место под локальные переменные. Инструкция `link` обычно используется в начале функции, чтобы подготовить место для хранения локальных переменных.
    - **Подробное описание операции:**
      1. Положить в стек текущее значение указанного адресного регистра (обычно A6, используемого как указатель кадра)
      2. Скопировать текущее значение указателя стека (A7) в указанный адресный регистр, установив новый указатель кадра
      3. Прибавить смещение к указателю стека (A7), чтобы зарезервировать место под локальные переменные
         - Для выделения места смещение должно быть отрицательным (например, -4 выделяет 4 байта)
         - После этого к локальным переменным можно обращаться по отрицательным смещениям от указателя кадра
    - **Контекст использования:**
        - Обычно используется с A6 — регистром, который по соглашению служит указателем кадра
        - К локальным переменным обращаются через указатель кадра с отрицательными смещениями (например, `-4(A6)`)
        - К параметрам, переданным через стек, обращаются с положительными смещениями (например, `8(A6)`)
    - **Примеры:**

      ```assembly
      link A6, -8        ; Сохранить старый A6 в стеке, A6 = SP, вычесть 8 из SP для выделения места
      move.l D0, -4(A6)  ; Сохранить D0 в первую локальную переменную (4 байта от указателя кадра)
      move.l D1, -8(A6)  ; Сохранить D1 во вторую локальную переменную (8 байт от указателя кадра)
      ```

- **Удаление кадра (Unlink)**
    - **Синтаксис:** `unlk <address_register>`
    - **Описание:** Освобождает кадр стека в конце подпрограммы, восстанавливая указатель стека и указатель кадра в значения, которые они имели до выполнения соответствующей инструкции `link`. Инструкция `unlk` обычно является последней операцией перед возвратом из функции.
    - **Подробное описание операции:**
      1. Скопировать указатель кадра (указанный адресный регистр, обычно A6) в указатель стека (A7)
         - Это фактически удаляет все локальные переменные, возвращая указатель стека в положение до их выделения
      2. Снять значение с вершины стека в указанный адресный регистр
         - Это восстанавливает предыдущее значение указателя кадра, сохранённое инструкцией `link`
    - **Контекст использования:**
        - Всегда используется в паре с соответствующей инструкцией `link`
        - Обычно за ней следует инструкция `rts` (возврат из подпрограммы)
        - Корректно освобождает все локальные переменные, созданные в функции
    - **Примеры:**

      ```assembly
      unlk A6            ; SP = A6 (освобождение локальных переменных), затем снять сохранённый указатель кадра в A6
      rts                ; Вернуться из подпрограммы
      ```

      Пример полной функции:

      ```assembly
      my_function:
          link A6, -12         ; Создать кадр стека с 12 байтами под локальные переменные
          move.l 8(A6), D0     ; Обратиться к параметру, переданному через стек (положительное смещение)
          move.l D0, -4(A6)    ; Сохранить в локальную переменную (отрицательное смещение)
          ; ... тело функции ...
          unlk A6              ; Уничтожить кадр стека
          rts                  ; Вернуться из подпрограммы
      ```
