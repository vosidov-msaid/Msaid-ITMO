# Документация по архитектуре набора команд (ISA) Acc32

Acc32 — простая аккумуляторная архитектура набора команд, созданная в учебных целях. В этой документации описаны инструкции, доступные в ISA Acc32, их синтаксис и семантика.

## Обзор архитектуры

Acc32 — 32-битная аккумуляторная архитектура. Её особенности:

- Один регистр общего назначения — аккумулятор (Acc)
- Два флага состояния: переполнение (V) и перенос (C)
- Ввод-вывод, отображённый на память (memory-mapped I/O)
- Простой набор команд, ориентированный на операции с аккумулятором

Эта архитектура отлично подходит новичкам, чтобы разобраться в основах устройства компьютера без сложностей, связанных с множеством регистров.

Комментарии в ассемблере Acc32 обозначаются символом `;`.

## Специфичные для ISA представления состояния

- `Acc:dec`, `Acc:hex` — регистр `Acc`.
- `V` — флаг переполнения.
- `C` — флаг переноса.

## Инструкции

Размер инструкции: 1 байт опкода плюс операнд — 4 байта для операнда в полное машинное слово, 2 байта
для узкого операнда. `load_imm`, `load_addr`, `store_addr`, `store_ind` и все инструкции управления
потоком выполнения содержат полное слово. `load` и `store` содержат смещение относительно самой
инструкции. Арифметические и побитовые инструкции содержат абсолютный адрес, причём тоже узкий — они
читают ячейку памяти, просто не могут адресовать ячейку выше 64 КиБ.

### Инструкции перемещения данных

- **Загрузка непосредственного значения (Load Immediate)**
    - **Синтаксис:** `load_imm <value>`
    - **Описание:** Загрузить непосредственное значение в аккумулятор.
    - **Операция:** `acc <- <value>`

- **Загрузка (Load)**
    - **Синтаксис:** `load <offset>`
    - **Описание:** Загрузить в аккумулятор значение по относительному адресу.
    - **Операция:** `acc <- mem[pc + <offset>]`

- **Сохранение (Store)**
    - **Синтаксис:** `store <offset>`
    - **Описание:** Сохранить значение аккумулятора по относительному адресу.
    - **Операция:** `mem[pc + <offset>] <- acc`

- **Загрузка по адресу (Load Address)**
    - **Синтаксис:** `load_addr <address>`
    - **Описание:** Загрузить в аккумулятор значение по указанному адресу.
    - **Операция:** `acc <- mem[<address>]`

- **Сохранение по адресу (Store Address)**
    - **Синтаксис:** `store_addr <address>`
    - **Описание:** Сохранить значение аккумулятора по указанному адресу.
    - **Операция:** `mem[<address>] <- acc`

- **Загрузка по адресу из аккумулятора (Load Acc)**
    - **Синтаксис:** `load_acc`
    - **Описание:** Загрузить в аккумулятор значение по адресу, который находится в аккумуляторе.
    - **Операция:** `acc <- mem[acc]`

- **Косвенное сохранение (Store Indirect)**
    - **Синтаксис:** `store_ind <address>`
    - **Описание:** Сохранить значение аккумулятора по косвенному адресу.
    - **Операция:** `mem[mem[<address>]] <- acc`

### Арифметические инструкции

- **Сложение (Add)**
    - **Синтаксис:** `add <address>`
    - **Описание:** Прибавить к аккумулятору значение по указанному адресу.
    - **Операция:** `acc <- acc + mem[<address>]`, устанавливаются флаги `C` и `V`.

- **Вычитание (Subtract)**
    - **Синтаксис:** `sub <address>`
    - **Описание:** Вычесть из аккумулятора значение по указанному адресу.
    - **Операция:** `acc <- acc - mem[<address>]`, устанавливаются флаги `C` и `V`.

- **Умножение (Multiply)**
    - **Синтаксис:** `mul <address>`
    - **Описание:** Умножить аккумулятор на значение по указанному адресу.
    - **Операция:** `acc <- acc * mem[<address>]`, устанавливаются флаги `C` и `V`.

- **Деление (Divide)**
    - **Синтаксис:** `div <address>`
    - **Описание:** Разделить аккумулятор на значение по указанному адресу.
    - **Операция:** `acc <- acc / mem[<address>]`

- **Остаток (Remainder)**
    - **Синтаксис:** `rem <address>`
    - **Описание:** Вычислить остаток от деления аккумулятора на значение по указанному адресу.
    - **Операция:** `acc <- acc % mem[<address>]`

- **Сброс переполнения (Clear Overflow)**
    - **Синтаксис:** `clv`
    - **Описание:** Сбросить флаг переполнения.
    - **Операция:** `overflow <- 0`

- **Сброс переноса (Clear Carry)**
    - **Синтаксис:** `clc`
    - **Описание:** Сбросить флаг переноса.
    - **Операция:** `carry <- 0`

### Побитовые инструкции

- **Сдвиг влево (Shift Left)**
    - **Синтаксис:** `shiftl <address>`
    - **Описание:** Сдвинуть аккумулятор влево на количество бит, хранящееся по указанному адресу (флаг переноса не используется).
    - **Операция:** `acc <- acc << mem[<address>]`

- **Сдвиг вправо (Shift Right)**
    - **Синтаксис:** `shiftr <address>`
    - **Описание:** Сдвинуть аккумулятор вправо на количество бит, хранящееся по указанному адресу, с сохранением знака (флаг переноса не используется).
    - **Операция:** `acc <- acc >> mem[<address>]`

- **Побитовое И (Bitwise AND)**
    - **Синтаксис:** `and <address>`
    - **Описание:** Выполнить побитовое И аккумулятора и значения по указанному адресу.
    - **Операция:** `acc <- acc & mem[<address>]`

- **Побитовое ИЛИ (Bitwise OR)**
    - **Синтаксис:** `or <address>`
    - **Описание:** Выполнить побитовое ИЛИ аккумулятора и значения по указанному адресу.
    - **Операция:** `acc <- acc | mem[<address>]`

- **Побитовое исключающее ИЛИ (Bitwise XOR)**
    - **Синтаксис:** `xor <address>`
    - **Описание:** Выполнить побитовое исключающее ИЛИ аккумулятора и значения по указанному адресу.
    - **Операция:** `acc <- acc ^ mem[<address>]`

- **Побитовое НЕ (Bitwise NOT)**
    - **Синтаксис:** `not`
    - **Описание:** Выполнить побитовое НЕ (инверсию) аккумулятора.
    - **Операция:** `acc <- ~acc`

### Инструкции управления потоком выполнения

- **Безусловный переход (Jump)**
    - **Синтаксис:** `jmp <address>`
    - **Описание:** Перейти по указанному адресу.
    - **Операция:** `pc <- <address>`

- **Переход, если равно нулю (Branch if Equal to Zero)**
    - **Синтаксис:** `beqz <address>`
    - **Описание:** Перейти по указанному адресу, если аккумулятор равен нулю.
    - **Операция:** `if acc == 0 then pc <- <address>`

- **Переход, если не равно нулю (Branch if Not Equal to Zero)**
    - **Синтаксис:** `bnez <address>`
    - **Описание:** Перейти по указанному адресу, если аккумулятор не равен нулю.
    - **Операция:** `if acc != 0 then pc <- <address>`

- **Переход, если больше нуля (Branch if Greater Than Zero)**
    - **Синтаксис:** `bgtz <address>`
    - **Описание:** Перейти по указанному адресу, если аккумулятор больше нуля.
    - **Операция:** `if acc > 0 then pc <- <address>`

- **Переход, если больше или равно нулю (Branch if Greater Than or Equal to Zero)**
    - **Синтаксис:** `bgez <address>`
    - **Описание:** Перейти по указанному адресу, если аккумулятор больше или равен нулю.
    - **Операция:** `if acc >= 0 then pc <- <address>`

- **Переход, если меньше нуля (Branch if Less Than Zero)**
    - **Синтаксис:** `bltz <address>`
    - **Описание:** Перейти по указанному адресу, если аккумулятор меньше нуля.
    - **Операция:** `if acc < 0 then pc <- <address>`

- **Переход, если установлен флаг переполнения (Branch if Overflow Set)**
    - **Синтаксис:** `bvs <address>`
    - **Описание:** Перейти по указанному адресу, если флаг переполнения установлен.
    - **Операция:** `if overflow == 1 then pc <- <address>`

- **Переход, если флаг переполнения сброшен (Branch if Overflow Clear)**
    - **Синтаксис:** `bvc <address>`
    - **Описание:** Перейти по указанному адресу, если флаг переполнения сброшен.
    - **Операция:** `if overflow == 0 then pc <- <address>`

- **Переход, если установлен флаг переноса (Branch if Carry Set)**
    - **Синтаксис:** `bcs <address>`
    - **Описание:** Перейти по указанному адресу, если флаг переноса установлен.
    - **Операция:** `if carry == 1 then pc <- <address>`

- **Переход, если флаг переноса сброшен (Branch if Carry Clear)**
    - **Синтаксис:** `bcc <address>`
    - **Описание:** Перейти по указанному адресу, если флаг переноса сброшен.
    - **Операция:** `if carry == 0 then pc <- <address>`

- **Останов (Halt)**
    - **Синтаксис:** `halt`
    - **Описание:** Остановить машину.

### Почему у нас нет

- **Сложение с непосредственным значением (Add Immediate)**
    - **Синтаксис:** `addi <const>`
    - **Описание:** Прибавить к аккумулятору непосредственное значение.
    - **Операция:** `acc <- acc + <const>`
    - Почему нет: если у вас есть `const_1`, почему бы просто не написать `add const_1`?
- **Косвенная загрузка (Load Indirect)**
    - **Синтаксис:** `load_ind <address>`
    - **Описание:** Загрузить значение из памяти по косвенному адресу.
    - **Операция:** `acc <- mem[pc]`
    - Почему нет: связка `load_addr` + `load_acc` выглядит естественнее для аккумуляторной архитектуры.
- **Сравнение (Compare)**
    - **Синтаксис:** `cmp <address>`
    - **Описание:** Сравнить аккумулятор со значением и установить только флаги.
    - **Операция:** `acc - mem[pc]` и установка флагов `Z` (пока не существует), `C` и `V`
    - Почему нет: порождает множество несогласованных состояний.
