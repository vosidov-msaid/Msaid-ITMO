# Документация по архитектуре набора команд (ISA) F32a

F32a — стековая архитектура набора команд, созданная в учебных целях. В этой документации описаны инструкции, доступные в ISA F32a, их синтаксис и семантика.

## Обзор архитектуры

F32a — 32-битная стековая архитектура, вдохновлённая Forth-системами. Её особенности:

- Два основных стека: стек данных и стек возвратов
- Два регистра общего назначения: A и B
- Стековые операции, упрощающие решение многих задач программирования
- Расширенный арифметический режим (Extended Arithmetic Mode, EAM) для операций, зависящих от переноса
- Флаг переноса для арифметических операций
- Ввод-вывод, отображённый на память (memory-mapped I/O)

Стековая архитектура предлагает иную парадигму программирования по сравнению с регистровыми архитектурами, поэтому она отлично подходит для знакомства с альтернативными моделями вычислений.

Комментарии в ассемблере F32a обозначаются символом `\`.

Вдохновлено [F18a](https://www.greenarraychips.com/home/documents/greg/DB001-221113-F18a.pdf)

## Специфичные для ISA представления состояния

- `A:dec`, `A:hex` — регистр `A`.
- `B:dec`, `B:hex` — регистр `B`.
- `T:dec`, `T:hex` — вершина стека данных.
- `S:dec`, `S:hex` — второе значение в стеке данных.
- `R:dec`, `R:hex` — вершина стека возвратов.
- `stack:dec`, `stack:hex` — весь стек данных.
- `rstack:dec`, `rstack:hex` — весь стек возвратов.
- `EAM` — расширенный арифметический режим (1 — включён, 0 — выключен).
- `C` — флаг переноса (1 — установлен, 0 — сброшен).

### Использование стеков

Симулятор отслеживает максимальную глубину (самый глубокий достигнутый уровень) каждого стека за весь прогон и предоставляет её через две итоговые переменные представления. Это итоговые значения за весь прогон, поэтому используйте их со `slice: last`.

- `f32a:data-stack-max` — максимальная глубина стека данных, достигнутая во время выполнения.
- `f32a:return-stack-max` — максимальная глубина стека возвратов, достигнутая во время выполнения.

Пример — вывести сводку по глубине стеков в конце симуляции:

```yaml
reports:
    - name: stacks
      slice: last
      view: |
        f32a:data-stack-max:   {f32a:data-stack-max}
        f32a:return-stack-max: {f32a:return-stack-max}
```

Для `factorial.s`, вычисляющего `4!`, сводка выглядит так:

```text
f32a:data-stack-max:   5
f32a:return-stack-max: 3
```

Глубина стека возвратов показывает, насколько глубоко были вложены рекурсивные/вложенные вызовы; глубина стека данных ограничивает, сколько операндов было «живо» одновременно. Это полезно для выбора размера области под стек и для обнаружения неконтролируемой рекурсии.

Обе строки также выводятся вместе общим итоговым блоком `{isa-specific}`, что позволяет использовать единый шаблон отчёта для всех ISA.

## Инструкции

Размер инструкции: 1 байт на опкод, 4 байта на каждый аргумент.

### Расширенный арифметический режим (EAM)

Расширенный арифметический режим (EAM) — режим, позволяющий выполнять сложение с учётом бита переноса. Подробности см. в описании инструкции `add`.

### Флаг переноса

Большинство инструкций сбрасывают (обнуляют) флаг переноса. В частности, любая инструкция, кладущая значение в стек данных, сбрасывает флаг переноса как побочный эффект. Исключения: `add` (устанавливает флаг переноса в зависимости от переполнения) и `dup` (сохраняет флаг переноса).

### Инструкции перемещения данных

- **Литерал (Literal)**
    - **Синтаксис:** `<value>` или `lit <value>`
    - **Описание:** Положить непосредственное значение в стек данных. Ключевое слово `lit` необязательно — достаточно просто числа, шестнадцатеричного значения (`0xFF`) или символьного литерала (`'A'`).
    - **Операция:** `dataStack.push(<value>)`

- **Чтение по адресу (Fetch from Address)**
    - **Синтаксис:** `@p <address>`
    - **Описание:** Положить в стек данных значение по указанному адресу.
    - **Операция:** `dataStack.push(mem[<address>])`

- **Чтение (Fetch)**
    - **Синтаксис:** `@`
    - **Описание:** Положить в стек данных значение по адресу из регистра A.
    - **Операция:** `dataStack.push(mem[A])`

- **Чтение с инкрементом (Fetch Plus)**
    - **Синтаксис:** `@+`
    - **Описание:** Положить в стек данных значение по адресу из регистра A и увеличить A на единицу.
    - **Операция:** `dataStack.push(mem[A]); A <- A + 1`

- **Чтение по B (Fetch B)**
    - **Синтаксис:** `@b`
    - **Описание:** Положить в стек данных значение по адресу из регистра B.
    - **Операция:** `dataStack.push(mem[B])`

- **Запись по адресу (Store to Address)**
    - **Синтаксис:** `!p <address>`
    - **Описание:** Записать значение с вершины стека данных по указанному адресу.
    - **Операция:** `mem[<address>] <- dataStack.pop()`

- **Запись (Store)**
    - **Синтаксис:** `!`
    - **Описание:** Записать значение с вершины стека данных по адресу из регистра A.
    - **Операция:** `mem[A] <- dataStack.pop()`

- **Запись с инкрементом (Store Plus)**
    - **Синтаксис:** `!+`
    - **Описание:** Записать значение с вершины стека данных по адресу из регистра A и увеличить A на единицу.
    - **Операция:** `mem[A] <- dataStack.pop(); A <- A + 1`

- **Запись по B (Store B)**
    - **Синтаксис:** `!b`
    - **Описание:** Записать значение с вершины стека данных по адресу из регистра B.
    - **Операция:** `mem[B] <- dataStack.pop()`

- **Запись в A (A-Store)**
    - **Синтаксис:** `a!`
    - **Описание:** Записать значение с вершины стека данных в регистр A.
    - **Операция:** `A <- dataStack.pop()`

- **Запись в B (B-Store)**
    - **Синтаксис:** `b!`
    - **Описание:** Записать значение с вершины стека данных в регистр B.
    - **Операция:** `B <- dataStack.pop()`

- **Чтение A (A-Fetch)**
    - **Синтаксис:** `a`
    - **Описание:** Положить значение регистра A в стек данных.
    - **Операция:** `dataStack.push(A)`

### Арифметические инструкции

- **Сложение (Add)**
    - **Синтаксис:** `+`
    - **Описание:** Сложить два верхних значения стека данных.
    - **Операция (без EAM):** `dataStack.push(dataStack.pop() + dataStack.pop()), set carry flag`
    - **Операция (с EAM):** `dataStack.push(dataStack.pop() + dataStack.pop() + carry), set carry flag`

- **Шаг умножения (Multiply Step)**
    - **Синтаксис:** `+*`
    - **Описание:** Выполнить один шаг умножения.
    - **Операция:** `T <- T + (if A[0] then S else 0); A <- A >> 1; if T[0] then A[31] <- 1 else A[31] <- 0; T <- T >> 1`

- **Шаг деления (Divide Step)**
    - **Синтаксис:** `+/`
    - **Описание:** Выполнить один микрошаг **деления с восстановлением остатка** (restoring division).
        - Делимое — `A`
        - Делитель — `mem[B]`
        - Частичный остаток — `S`
        - Частичное частное — `T`
    - **Операция:**
        1. `S <- S << 1`
        2. `if A[31] then S[0] <- 1`
        3. `A <- A << 1`
        4. `T <- T << 1`
        5. `if S >= mem[B] then`
            - `S <- S - mem[B]`
            - `T[0] <- 1`
    - [**Пример на Python**](https://github.com/ryukzak/wrench/blob/master/example/step-by-step-div.py)

- **Сдвиг влево (Left Shift)**
    - **Синтаксис:** `2*`
    - **Описание:** Сдвинуть значение на вершине стека данных влево на один бит.
    - **Операция:** `dataStack.push(dataStack.pop() << 1)`

- **Сдвиг вправо (Right Shift)**
    - **Синтаксис:** `2/`
    - **Описание:** Сдвинуть значение на вершине стека данных вправо на один бит с сохранением знака (арифметический сдвиг).
    - **Операция:** `dataStack.push(dataStack.pop() >> 1)`

- **Инверсия (Invert)**
    - **Синтаксис:** `inv`
    - **Описание:** Инвертировать все биты значения на вершине стека данных.
    - **Операция:** `dataStack.push(~dataStack.pop())`

- **Расширенные арифметические инструкции (Extend Arithmetic Instructions)**
    - **Синтаксис:** `eam`
    - **Описание:** Снять значение со стека данных и установить по нему флаг EAM.
    - **Операция:** `eam <- dataStack.pop()`

### Побитовые инструкции

- **И (And)**
    - **Синтаксис:** `and`
    - **Описание:** Выполнить побитовое И над двумя верхними значениями стека данных.
    - **Операция:** `dataStack.push(dataStack.pop() & dataStack.pop())`

- **Исключающее ИЛИ (Xor)**
    - **Синтаксис:** `xor`
    - **Описание:** Выполнить побитовое исключающее ИЛИ над двумя верхними значениями стека данных.
    - **Операция:** `dataStack.push(dataStack.pop() ^ dataStack.pop())`

### Инструкции работы со стеком

- **Удаление (Drop)**
    - **Синтаксис:** `drop`
    - **Описание:** Удалить значение с вершины стека данных.
    - **Операция:** `dataStack.pop()`

- **Дублирование (Dup)**
    - **Синтаксис:** `dup`
    - **Описание:** Продублировать значение на вершине стека данных.
    - **Операция:** `dataStack.push(dataStack.top()), carry flag does not change` (флаг переноса не меняется)

- **Копирование второго (Over)**
    - **Синтаксис:** `over`
    - **Описание:** Скопировать второе значение стека данных на вершину, увеличив глубину стека.
    - **Операция:** `T <- dataStack.pop(); S <- dataStack.pop(); dataStack.push(S); dataStack.push(T); dataStack.push(S)`

### Инструкции управления потоком выполнения

- **Возврат (Return)**
    - **Синтаксис:** `;`
    - **Описание:** Вернуться из подпрограммы.
    - **Операция:** `p <- returnStack.pop()`

- **Вызов (Call)**
    - **Синтаксис:** `<label>`
    - **Описание:** Вызвать подпрограмму по указанной метке.
    - **Операция:** `returnStack.push(p); p <- <label>`

- **Переход (Jump)**
    - **Синтаксис:** `<label> ;`
    - **Описание:** Перейти на указанную метку.
    - **Операция:** `p <- <label>`

- **Следующая итерация (Next)**
    - **Синтаксис:** `next <label>`
    - **Описание:** Перейти в цикле на указанную метку, уменьшив R на единицу.
    - **Операция:**
        - `if R != 0 then`
            - `R <- R - 1`
            - `p <- <label>`
        - `else returnStack.pop()`

- **Если (If)**
    - **Синтаксис:** `if <label>`
    - **Описание:** Перейти на указанную метку, если значение на вершине стека данных равно нулю.
    - **Операция:** `if dataStack.pop() == 0 then p <- <label>`

- **Если неотрицательно (Minus If)**
    - **Синтаксис:** `-if <label>`
    - **Описание:** Перейти на указанную метку, если значение на вершине стека данных неотрицательно.
    - **Операция:** `if dataStack.pop() >= 0 then p <- <label>`

- **Останов (Halt)**
    - **Синтаксис:** `halt`
    - **Описание:** Остановить машину.

### Инструкции работы с регистрами

- **Из R в T (RIntoT)**
    - **Синтаксис:** `r>`
    - **Описание:** Переместить значение с вершины стека возвратов в стек данных.
    - **Операция:** `dataStack.push(returnStack.pop())`

- **Из T в R (TIntoR)**
    - **Синтаксис:** `>r`
    - **Описание:** Переместить значение с вершины стека данных в стек возвратов.
    - **Операция:** `returnStack.push(dataStack.pop())`
